# 🧠 Успешный Mind — Интерактивная 3D WebGL платформа

Высокотехнологичный интерактивный 3D-лендинг нового поколения для экосистемы **«Успешный»** (`uspeshmind`).

Проект сочетает в себе вычислительную WebGL-графику на **Three.js**, кастомные шейдеры на GPU, интерактивный морфинг миллионов частиц (нейронный мозг → щит-флаг бренда → фирменное облако знаний), кинетическую виртуальную прокрутку (`asscroll`), побуквенную анимацию типографики (GSAP ScrollTrigger) и строгую неоновую тёмную эстетику.

---

## 🚀 Быстрый запуск

Для работы WebGL-шейдеров, потоковой загрузки бинарных 3D-моделей (`.glb`) и 32-битных текстур с плавающей запятой (`.exr`) через Web API `fetch`, запуск должен производиться через локальный веб-сервер.

### Способ 1: В один клик (Windows)
Просто запустите файл **`start.bat`** (или `start.ps1`):
```bat
start.bat
```
Сервер автоматически подберёт свободный порт и откроет сайт в браузере по адресу:  
👉 **http://localhost:8090/**

### Способ 2: Через Python
Встроенный многопоточный сервер с корректной отдачей MIME-типов для 3D и шрифтов:
```bash
python server.py
```

### Способ 3: Через Node.js / npx
```bash
npx serve . -p 8090
```

## ✨ Ключевые особенности и архитектура

### 1. 🌌 Вычислительный 3D WebGL Canvas (`<canvas id="canvas">`)
- **GPU-партиклы**: тысячи трёхмерных пирамидальных частиц, рендерящихся в реальном времени с поддержкой аппаратного ускорения.
- **Шейдерные карты**: 32-битная карта координат `images/pos-33.exr` (32-bit floating point EXR) и бинарные буферы `images/uspeshnyy_coords.bin`.
- **Интерактивный морфинг**: при виртуальной прокрутке сцены частицы перестраиваются между ключевыми 3D-состояниями:
  1. *Коллективный разум* (нейронный 3D-мозг).
  2. *Щит-флаг «Успешный»* (защищённость и стандарты).
  3. *Облако знаний и экосистема* (рассеивание в глубину резкости).
- **Интерактивность**: динамический расчёт глубины резкости (DoF), параллакс относительно позиции курсора мыши и гироскопа.
- **LOD (Level of Detail)**: набор оптимизированных 3D-мешей пирамид (`models/py-lod1.glb` … `models/py-lod7.glb`, `py-monbile.glb`) для обеспечения 60+ FPS даже на мобильных GPU.

### 2. 🎨 Брендинг и дизайн-система
- **Цветовая палитра**: глубокий космический фон `#080c10` с фирменным акцентным циан-свечением `#5fc1e8`.
- **Векторная графика**: выверенный SVG-логотип с кириллической надписью «УСПЕШНЫЙ» без артефактов и обрезаний на любых экранах.
- **Типографика**: полный набор премиального гротеска `PP Neue Montreal` (Light, Regular, SemiBold) в веб-форматах `.woff2` и `.woff`.
- **Полная русскоязычная локализация**:
  - Главная страница (`index.html`): Hero, Манифест («Зажигайте моменты озарения», «Создавайте лучшую культуру работы»), интерактивный слайдер команды, партнёры и инвесторы, футер.
  - Юридический блок: [Политика конфиденциальности](privacy.html) (`privacy.html` / `privacy/index.html`) и [Условия использования](terms.html) (`terms.html` / `terms/index.html`).

### 3. ⚡ Оптимизация производительности
- **Компактный размер**: весь репозиторий со всеми 3D-ассетами, звуками и шрифтами занимает всего **~4.1 MB**.
- **Чистый код без мусора**: удалены все неиспользуемые резервные копии, тестовые рендеры и устаревшие сторонние трекеры (PostHog, Intercom, GTM), что исключает сетевые задержки и ошибки в консоли.
- **Адаптивность**: поддержка экранов от мобильных смартфонов (390px с мобильным гамбургером) до ультрашироких 4K мониторов.
